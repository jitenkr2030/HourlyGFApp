## 🚀 Run the App (3 Steps)

```bash
# 1. Install dependencies
cd HourlyGFApp && npm install

# 2. Install iOS pods (Mac only)
cd ios && pod install && cd ..

# 3. Run
npm run android  # or npm run ios
```
